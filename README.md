# plantilla-legal

Public legal documents for the Plantilla iOS app, published by JC Mobile App Studio LLC.

## Live site

The privacy notice is published at: **https://jcmappstudio.github.io/plantilla-legal/**

The App Store privacy URL points here.

## Files

- `PRIVACY.md` — canonical privacy notice (markdown source)
- `index.html` — same content as a styled, accessible web page rendered via GitHub Pages
- `README.md` — this file

## How updates work

1. Edit `PRIVACY.md` and `index.html` together (keep them in sync)
2. Bump the "Last updated" date at the top of both
3. Commit and push to `main`
4. GitHub Pages republishes within a minute

For material changes (anything that changes what data we collect, how we use it, or what third parties we share it with), we also surface the update in the iOS app on next launch.
